# Skill index

- [ontology-discover](ontology-discover/SKILL.md) — Discover candidate concepts, relations and competency questions from a bounded domain or evidence corpus.
- [ontology-select](ontology-select/SKILL.md) — Choose and safely compose ontology domain templates using competency questions, not file formats alone.
- [ontology-model](ontology-model/SKILL.md) — Design typed entities, relations, direction, domain/range and cardinality for a reusable ontology template.
- [ontology-align](ontology-align/SKILL.md) — Reconcile synonyms, homonyms and cross-domain identities without silent semantic merges.
- [ontology-extract](ontology-extract/SKILL.md) — Extract evidence-linked candidate nodes and relation assertions from raw conversations, code or workflow sources.
- [ontology-resolve](ontology-resolve/SKILL.md) — Resolve instance identities, aliases, duplicate records and ambiguity with an auditable merge policy.
- [ontology-link](ontology-link/SKILL.md) — Create typed, evidence-backed edges and cross-domain traceability while preserving uncertain assertions.
- [ontology-constrain](ontology-constrain/SKILL.md) — Specify verifiable ontology invariants and acceptance criteria without confusing schema checks with truth.
- [ontology-verify](ontology-verify/SKILL.md) — Validate compiled ontology templates and evidence graphs, review conflicts, and report residual risks.
- [ontology-evolve](ontology-evolve/SKILL.md) — Plan versioned ontology changes and migrations without losing historical meaning or provenance.
- [ontology-query](ontology-query/SKILL.md) — Define competency-question-based semantic query and traversal contracts with provenance and authorization.
- [ontology-publish](ontology-publish/SKILL.md) — Publish validated versioned ontology artifacts, export provenance-rich graphs and document integration contracts.

These are reusable agent instructions, not hidden executables. Follow the evidence policy and choose only skills needed for the task.
